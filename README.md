# DHT_ESP8266_Thingspeak
"ESP8266 with DHT sensor sending data to ThingSpeak IoT Cloud

**DHT Sensor with ESP8266 + ThingSpeak**

This project reads Temperature & Humidity from a DHT11 sensor using an ESP8266 NodeMCU and uploads the data to ThingSpeak IoT Cloud for visualization.

**Hardware Required**

ESP8266 NodeMCU

DHT11 (or DHT22) sensor

Jumper wires

Setup

Install Arduino IDE

Add ESP8266 Board Manager

**Install Libraries:**

ESP8266WiFi

ThingSpeak

DHT Sensor Library

Edit the code with your WiFi SSID, Password, and ThingSpeak API Key

Upload the code to ESP8266

**ThingSpeak Dashboard**

Field 1 → Temperature (°C)

Field 2 → Humidity (%)
